# E-commerce UI Product Analytics

## Project overview

This project explores user behavior in an anonymized e-commerce platform with multiple user interface variants.

The goal is to identify bottlenecks in the customer journey, calculate key product metrics, compare user segments and propose an A/B test for improving conversion.

## Business problem

The product team wants to understand:

1. Where do users drop off in the customer journey?
2. Which user segments behave differently?
3. Do different UI variants demonstrate different product metrics?
4. What product hypothesis should be tested next?
5. Which metrics should be monitored before rolling out a change?

## Planned analysis

- Data quality checks
- Event taxonomy analysis
- User journey mapping
- Funnel analysis
- User segmentation
- Retention analysis
- UI variant comparison
- A/B test design
- Dashboard
- Product recommendations

## Repository structure

- `data/` — data description and local dataset folders
- `notebooks/` — exploratory and statistical analysis
- `sql/` — analytical SQL queries
- `dashboard/` — dashboard screenshots and description
- `docs/` — business requirements and product recommendations
- `src/` — reusable Python functions

## Dataset

The project uses the public dataset **Data-driven E-commerce UI Personalization: Going Beyond Product Recommendations** published on Mendeley Data.

Raw files are not stored in this repository. See `data/README.md` for download instructions.
