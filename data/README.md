# Data

## Source

This project uses the public dataset:

**Data-driven E-commerce UI Personalization: Going Beyond Product Recommendations**

Publisher: Mendeley Data  
DOI: `10.17632/sxmgyvxpv9.1`  
License: CC BY 4.0

## Dataset description

The dataset contains clickstream data from an anonymized online store with multiple UI variants.

The project initially uses the raw behavioral data from the `learning-dataset` catalog. Precomputed clustering results and conversion indicators are excluded from the initial analysis and may only be used later for validation.

## Local setup

Download the dataset from Mendeley Data and place the raw files in:

```text
data/raw/
```

Raw data files are intentionally excluded from version control.
